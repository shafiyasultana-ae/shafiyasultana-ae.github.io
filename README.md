## Tech Stack

- Pure HTML5, CSS3, and Vanilla JavaScript — no frameworks, no external dependencies
- All certificates embedded as Base64 — fully offline-capable once loaded
- Fonts loaded from Google Fonts (Orbitron, DM Sans, Space Mono)
- Features include smooth scroll, scroll-reveal animations, animated SGPA bars, and a certificate modal viewer with PDF and image support


## Projects Featured

### Design and Performance Analysis of a Truncated Linear Aerospike Nozzle

**Final Year Major Project** | Guide: Prof. Sathya Narayanan, MVJCE

CFD simulation using ANSYS Fluent on truncated aerospike nozzle configurations using k-epsilon and k-omega SST turbulence models.

- 30% truncation — Highest Thrust: 1077.7 N
- 45% truncation — Highest Exit Mach Number: 5.0

### Structural Design and Simulation of an Aircraft Wingbox

**Mini Project** | Guide: Prof. Gopinath, MVJCE

CAD modelling and FEA-based stress and deformation analysis with material comparison under simulated aerodynamic loading conditions.
